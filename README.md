# ИИ-ассистент для информационной панели

> Пример плагина для браузера Chrome, позволяющего создавать визуализации в Информационных панелях Платформы "Форсайт" на базе текстового запроса с использованием LLM

![Chrome](https://img.shields.io/badge/Chrome-Yes-brightgreen)
![Manifest V3](https://img.shields.io/badge/Manifest%20V3-Yes-orange)

## ✨ Возможности

- Формирование визуализации "на лету" по текстовому запросу
- Инжекция полученного результата в выбранный визуализатор Инфопанели
- Дополнительно формируется и копируется в буфер обмена HTML код внешнего плагина Инфопанели (можно использовать как  средство генерации примеров внешних плагинов)

## 🚀 Установка


### Установка вручную (для разработчиков)

1. Скачай этот репозиторий или последнюю версию.
2. Открой Chrome и перейди по адресу: `chrome://extensions/`
3. Включи режим **«Режим разработчика»** (в правом верхнем углу).
4. Нажми **«Загрузить распакованное расширение»**
5. Выбери папку с расширением.

По умолчанию доступ к LLM осуществляется по адресу http://localhost:1234/v1 (например, локальная LM Studio).
При необходимости внесите исправления в manifest.json и popus.js (константа API_BASE).

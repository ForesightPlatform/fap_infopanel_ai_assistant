# ИИ-ассистент для информационной панели

> Chrome-расширение, которое позволяет создавать визуализации для Информационных панелей Платформы «Форсайт» по текстовому запросу с помощью LLM (Large Language Model).

![Версия](https://img.shields.io/badge/Version-1.0.0-blue)
![Chrome](https://img.shields.io/badge/Chrome-Yes-brightgreen)
![Manifest V3](https://img.shields.io/badge/Manifest%20V3-Yes-orange)

## ✨ Возможности

- Формирование визуализации «на лету» по текстовому запросу
- Автоматическая вставка результата в выбранный визуализатор Инфопанели
- Генерация и копирование в буфер обмена HTML-кода внешнего плагина Инфопанели (удобно для создания примеров)

## 🚀 Установка

### Установка вручную (для разработчиков)

1. Скачайте репозиторий или последнюю версию.
2. Откройте Chrome и перейдите по адресу: `chrome://extensions/`
3. Включите режим **«Режим разработчика»** (в правом верхнем углу).
4. Нажмите кнопку **«Загрузить распакованное расширение»**.
5. Выберите папку с расширением.

**По умолчанию** расширение подключается к локальному LLM по адресу `http://localhost:1234/v1` (например, LM Studio).  
При необходимости измените адрес в файле `popup.js` (константа `API_BASE`).

## 🛠 Разработка и настройка

- Основной файл настроек — `manifest.json`
- Логика popup-окна — `popup/popup.js`
- Для изменения API-сервера отредактируйте константу `API_BASE` в `popup.js`
